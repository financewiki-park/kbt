# Bluetooth + Key Mapping Toggle

Installs a Kindle Scriptlet that toggles both `kindle-hid-passthrough` and
`kindle-button-mapper` with one tap.

The package does not alter startup services. It starts and stops the existing
HID Passthrough and Button Mapper programs only when the Scriptlet is tapped.

Requires Kindle HID Passthrough, including Button Mapper, to already be
installed on the Kindle.
